What is Arduino?

Arduino is an open-source electronics platform made for creating interactive projects. It uses a programmable microcontroller board that can read inputs from sensors and control outputs like LEDs, motors, and speakers. With simple coding in the Arduino IDE, beginners and experts can build robots, smart gadgets, and automation systems easily.

4. How to Install Arduino IDE

Where to Download

Get the latest Arduino IDE from the official Arduino website.

How to Install

Run the installer and follow the simple steps to install the IDE.

Selecting the Board

Go to Tools → Board and choose your Arduino model.

Selecting the COM Port

Go to Tools → Port and select the port your board is connected to.

Your First Program: Blink

What Blink does: Makes an LED blink on your Arduino board at a set interval.

Code Example:

void setup() {
  pinMode(LED_BUILTIN, OUTPUT); // Set the built-in LED pin as output
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH); // Turn LED on
  delay(1000);                     // Wait 1 second
  digitalWrite(LED_BUILTIN, LOW);  // Turn LED off
  delay(1000);                     // Wait 1 second
}

Explanation of each line:

  • void setup(): Runs once to initialize settings.
  • pinMode(LED_BUILTIN, OUTPUT): Sets the LED pin as output.
  • void loop(): Runs repeatedly after setup.
  • digitalWrite(LED_BUILTIN, HIGH): Turns the LED on.
  • delay(1000): Waits 1 second.

Setup & Loop Functions

The setup() function runs once when your Arduino board starts, and loop() runs repeatedly as long as the board is powered. Every Arduino program (called a sketch) needs these functions to work properly.
